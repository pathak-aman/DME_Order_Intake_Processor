Features

Everything a production intake needs

Built AI-native, deployed in minutes, ready for real-world fax chaos.

Intelligent PDF Extraction

Powered by Gemini Vision. Handles scanned faxes, rotated pages, and multi-page DME orders without breaking a sweat.

Zero-Guessing Policy

Missing fields are returned as null, never invented. NPI must be exactly 10 digits or it's flagged for review.

Per-User Auth Isolation

JWT Bearer authentication. Each user sees only their own orders — full tenant isolation, no shared data leakage.

Full CRUD API

Create, read, update, and delete orders. Manual entry or PDF upload — both supported. Full OpenAPI schema at /docs.

PostgreSQL Backed

SQLAlchemy ORM with Neon PostgreSQL. Orders persist across requests, sessions, and deployments.

Deployed on Vercel

Serverless Python backend + static frontend. Zero cold-start config, auto-scaling, and a public URL out of the box.

Workflow

From fax to structured data

Four steps from raw PDF to a verified, queryable order record.

1. Authenticate

Register an account and log in to get your JWT Bearer token. Each session is isolated to your user.

2. Upload the PDF

Drag and drop a faxed order — scanned, messy, multi-page. Our API accepts it all via POST /orders/upload.

3. AI Extracts & Validates

Gemini reads the document. Patient name, DOB, provider name, and NPI are extracted with strict validation. Ambiguous → null.

4. Review & Manage

The order lands in your dashboard. Edit, approve, or delete records. Full CRUD via the UI or the REST API.

REST API

Simple, predictable API

Full OpenAPI schema available at /docs. Integrate in minutes.

POST /orders/upload PDF → JSON 
# Upload a faxed DME order
curl -X POST /orders/upload \
  -H "Authorization: Bearer <token>" \
  -F "file=@order.pdf"

# Response:
{
  "id": 42,
  "patient_first_name": "John",
  "patient_last_name": "Doe",
  "patient_dob": "1980-05-14",
  "provider_name": "Dr. Jane Smith",
  "provider_npi": null,
  "status": "needs_review"
}
POST /auth/token JWT Auth 
# Register
curl -X POST /auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@clinic.org","password":"••••"}'

# Login → get token
curl -X POST /auth/token \
  -d "username=you@clinic.org&password=••••"

# Response:
{
  "access_token": "eyJhbGci...",
  "token_type": "bearer"
}

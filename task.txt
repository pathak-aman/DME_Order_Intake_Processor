Full Stack AI Engineer: Take-home
assessment
Build a small order-intakeservice, the way an AI-native team would

Background
Much of healthcare still runs on faxed orders. A durable medical equipment (DME) supplier
receives a scanned PDF from a doctor's office, and a person types the patient and provider
details into a system by hand. GenHealth automates that work, and a wrong value means a
denied claim or a delayed patient.
GenHealth is AI-native. We use agents wherever we can, because they give us leverage and
help us move faster. Build this the way you would on a team like ours.
What happens next: If your submission works, we'll schedule a 90-minute pair
programming session where we make a small change to your project together, using AI the
way you normally would.

The Task
Build a REST API in Python that does the following, plus whatever else you think a
production-ready MVP needs:
1. Performs CRUD operations on an “Order” and saves it to a database
2. Accepts an uploaded PDF and extracts the patient’s first name, last name and date of
birth, and the ordering provider’s name and NPI (we will test it with PDFs you have
never seen, including scanned faxes and messy, multi-page documents)
3. Checks the extracted values before saving them, and doesn’t guess when a field is
missing
4. Requires authentication, so each user can only see their own orders
5. Is deployed somewhere publicly accessible
